# 规则

### 对投稿人而言

1. 请去主页规定的地方进行投稿，出错地方一律不理。
2. 出现以下行为的永久不得投稿
   1. 占用投稿区资源
   2. 在投稿区恶意挑事
   3. 因看他人不爽进行投稿
   4. -待定-

{% hint style="warning" %}
这个维基是用来挂逆天人的，个人事件除非他对你造成了一定伤害，本维基一律不受理

如果你是因为<mark style="color:red;">**看不惯**</mark>对方所以才挂人的，那么不好意思，我们挺愿意收录你的
{% endhint %}

### 对合作者而言

1. 请不要胡乱改动
2. 保证数据新鲜
3. 定期处理投稿区的投稿
